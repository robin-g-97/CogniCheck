# CogniCheck Methodology

CogniCheck is a decision-support review method for BI reports and dashboards.

The central question is:

> Does this report help the intended user make the intended decision?

CogniCheck combines:

- BI requirements thinking
- cognitive psychology
- data visualization principles
- decision-support quality
- practical report design feedback

## Core principle

Data understanding starts with understanding people.

A report should not only be technically correct. It should also be cognitively usable and aligned with the decision context.

## What CogniCheck evaluates

CogniCheck evaluates two main dimensions:

1. Cognitive load
2. Decision alignment

A good report reduces unnecessary cognitive effort and makes the relevant decision easier to understand.

## Analysis approach

When analyzing a report, use the following order:

1. Understand the user context.
2. Understand the decision the report should support.
3. Inspect the report structure and visual hierarchy.
4. Identify sources of cognitive load.
5. Evaluate whether the report supports the intended decision.
6. Give practical recommendations.

## Important rule

Do not assume missing context. If the context is unclear, say so explicitly.

## Key concepts

### Attention

Evaluate what visually stands out first. Check whether this matches the most important decision signal.

### Structure

Evaluate whether related information is grouped logically. Use Gestalt principles such as proximity, similarity, enclosure and alignment.

### Working memory

Evaluate whether users must mentally reconstruct meaning by combining scattered elements. The more users must remember and compare manually, the higher the cognitive load.

### Change visibility

Evaluate whether trends, differences, thresholds and deviations are explicit. Users should not have to search for what changed.

### Decision support

Evaluate whether the report gives the user enough information to decide what action is needed.

## Tone

Use a professional BI consulting tone:

- clear
- practical
- constructive
- specific
- business-oriented

Avoid vague advice such as "make it cleaner". Explain what should change and why.
