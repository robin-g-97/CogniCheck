SCORING ATTITUDE

Score strictly. Avoid central tendency bias. Use the full 1-10 range.

Important:
- A professional-looking report is not automatically good.
- A report with many visuals is not automatically a dashboard.
- A report with references, budgets or deltas is not automatically decision-ready.
- A score of 7 or higher requires clear evidence that the report supports fast, reliable interpretation.
- A 5 or 6 is not a bad score. It often means the report is operationally useful but not yet a strong decision dashboard.
- Always evaluate from the perspective of the intended user's cognitive effort and the stated decision context.

SCORE MEANING

1 = unusable; severe design failure
2 = very poor; user cannot reliably extract meaning
3 = poor; some structure, but high cognitive effort
4 = weak; usable only with significant manual interpretation
5 = acceptable; works, but not decision-ready
6 = decent operational report; clear but cognitively demanding
7 = good analytical dashboard; mostly clear, some friction
8 = strong decision-support dashboard; minor improvements only
9 = excellent; highly intentional and immediately interpretable
10 = exceptional; near best-in-class

REPORT MATURITY CLASSIFICATION

Before scoring, silently classify the report into one of four maturity levels. Mention the maturity level briefly in the Executive summary, but do not create a separate maturity score.

LEVEL 1 - DATA DUMP OR SPREADSHEET-LIKE REPORT
Mostly tables, raw numbers, dense matrices or operational exports. Little visual hierarchy. User must inspect many cells manually.
Typical score range: 1-4.

LEVEL 2 - OPERATIONAL REPORT
Useful for monitoring and periodic control. Contains structure, filters, references and details, but requires active interpretation.
Typical score range: 4-6.

LEVEL 3 - ANALYTICAL DASHBOARD
Clear analytical structure, meaningful comparisons, supporting visuals and some hierarchy. Still requires some interpretation.
Typical score range: 6-8.

LEVEL 4 - DECISION DASHBOARD
One clear decision question, strong focal hierarchy, immediate exception detection, low mental reconstruction and clear next-step relevance.
Typical score range: 8-10.

GLOBAL CAP RULES

Apply these maximum score rules before assigning scores:

- If the report is mainly a data dump or spreadsheet-like matrix, no score can be above 5.
- If the report is an operational report, no score can be above 6 unless there is strong evidence of decision-readiness.
- If there is no clearly identifiable primary decision question, decision alignment cannot score above 6.
- If the user must inspect more than three separate visuals or tables to answer the main question, cognitive load cannot score above 6.
- If there are more than three competing focal points, cognitive load cannot score above 6.
- If deviations are only shown numerically and not visually prioritized, decision alignment cannot score above 6.
- If the report looks polished but the user still has to reconstruct the meaning manually, do not score above 6.
- A score of 8 or higher requires a clear dominant reading path, visual prioritization of deviations and strong reduction of cognitive effort.

NEGATIVE EVIDENCE CHECK

For each score, explicitly check what prevents a high score.

A score may only be 7 or higher if most of the following are true:
- The main message is visible within 5 seconds.
- Related information is visually grouped.
- The user does not need to mentally combine more than two distant elements.
- Visual emphasis matches business importance.
- Exceptions or deviations are visually encoded, not only shown as numbers.
- The page has one dominant reading path.
- Attention competition is limited.
- Detail supports the main message instead of competing with it.

If several of these are false, the score must usually be 6 or lower.

BENCHMARK CALIBRATION

Use these examples to calibrate scoring:

- Spreadsheet-like financial matrix with many rows, totals, actuals, budgets and variances, but limited visual hierarchy: expected score range 4-6.
- Busy Power BI page with many charts, slicers, cards, tables and multiple focal points: expected score range 4-6.
- Cluttered dashboard with many colors, heavy borders, mixed chart types, weak hierarchy, decorative styling and chart junk: expected score range 2-4.
- Clean decision dashboard with one primary KPI, explicit delta, visible exception logic, supporting trend, clear reference point and detail-on-demand: expected score range 8-10.

COGNITIVE LOAD SCORE, 1-10

Assess:
- visual complexity
- attention competition
- information density
- mental reconstruction required
- clarity of hierarchy
- use of grouping
- change visibility
- label clarity
- chart junk, borders, gridlines and unnecessary detail
- whether the detail supports or obscures the main message

Anchors:
1-2 = very high cognitive load; core message buried; severe clutter or almost no structure.
3-4 = significant effort required; user must inspect and combine many elements.
5-6 = manageable but cognitively demanding; message is findable, not immediate.
7-8 = low extraneous load; main message is clear; detail is logically layered.
9-10 = very low cognitive friction; instant comprehension; strong detail-on-demand.

Decision rules:
- If the page is mainly a table or matrix requiring cell-by-cell inspection, cognitive load cannot score above 6.
- If the report contains many slicers, charts and tables without clear prioritization, cognitive load cannot score above 6.
- If the user must compare more than three separate visuals or tables to answer the main question, cognitive load cannot score above 6.
- If the report is designed for exploration rather than immediate decision support, do not score above 6 unless structure is exceptionally clear.

DECISION ALIGNMENT SCORE, 1-10

Assess:
- alignment between dashboard content and the stated main decision
- whether required KPIs are present
- whether the user can see what action is needed
- whether the report provides enough context
- whether the report contains distracting or irrelevant information
- whether it supports the stated usage frequency and audience
- whether references, targets, thresholds, benchmarks or prior-period comparisons are visible
- whether deviations are visually prioritized
- whether the user can tell what is good, bad, expected or exceptional

Anchors:
1-2 = no meaningful decision support; mostly raw information.
3-4 = weak decision support; user must infer relevance and action.
5-6 = useful operational monitoring, but actionability is limited.
7-8 = good decision support; main decision is mostly supported with minor gaps.
9-10 = excellent decision support; decision, evidence, exception logic and next-step relevance are immediately clear.

Decision rules:
- If the primary decision is unclear or missing, decision alignment cannot score above 6.
- If required KPIs are missing or only implied, decision alignment cannot score above 6.
- If deviations are shown only as numbers and not visually encoded, decision alignment cannot score above 6.
- If the user cannot tell whether action is needed within 5 seconds, decision alignment cannot score above 6.
- If important reference points are missing, subtract from the score and explain the business risk.
